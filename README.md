One image summing up the world news of Thursday 26 November 2026:
32 stories across 7 regions on a single front page — three leads, a
numbered world map, ten story cards and nineteen briefs, every story
carrying its named source and a REPORTED / CLAIM / PROPOSED label.

## Run it

```sh
python3 main.py
```

Writes `out/entry.png` (or `$MAKEFUN_OUTPUT_DIR/entry.png`). The image
is committed as `entry.png`; `render.py` is the build-time script that
drew it. No network, no clock: two runs write identical bytes.
